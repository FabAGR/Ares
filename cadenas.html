SERRURE CONNECTÉE — PORTAIL

Ouvrir le portail

Le Cocon du Bassin · Arès
1
Composez le code Le code vous a été envoyé par message sur Airbnb. Tapez-le sur le clavier numérique (1 à 9, 0).
The code was sent to you via Airbnb messaging. Type it on the keypad (1 to 9, 0).
2
Bouton déverrouiller (en bas à droite) Appuyez dessus pour valider. Le cadenas s'ouvre.
Press it to confirm. The padlock unlocks.
⚠️ Une fois le portail ouvert Raccrochez le cadenas sur le portail et refermez-le (repoussez l'anse jusqu'au clic). C'est obligatoire à chaque fois : s'il reste ouvert, il se met à sonner.

Once the gate is open, hook the padlock back onto the gate and lock it shut (push the shackle down until it clicks). This is required every time: if left unlocked, it will start beeping.
