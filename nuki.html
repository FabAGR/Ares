Ouvrir la porte

Le Cocon du Bassin · Arès
1
Depuis l'extérieur
1
Composez le code Le même code que celui du portail. Tapez-le sur le clavier — c'est tout, pas besoin de valider : la porte s'ouvre dès le dernier chiffre. Le même code sert aussi à refermer en repartant.
The same code as the gate. Type it on the keypad — that's it, no need to confirm: the door unlocks after the last digit. The same code also locks it when you leave.
2
Depuis l'intérieur
1
Bouton rond central Une pression verrouille ou déverrouille la porte, sans code. Pratique pour sortir sur la terrasse ou pour verrouiller le soir. Ça ne permet pas de rentrer : depuis l'extérieur, c'est le clavier qui commande.
One press locks or unlocks the door, no code needed. Handy for stepping onto the terrace or locking up at night. It doesn't let you back in: from outside, the keypad is what unlocks the door.
💡 À retenir Dehors → composez juste le code. Dedans → juste le bouton central. Les deux commandent la même porte.

Outside → just type the code. Inside → just the centre button. Both control the same door.
