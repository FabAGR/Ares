Arriver au CoconArriving at the Cocon

Votre code personnel vous est envoyé par message Airbnb avant l'arrivée. Le même code ouvre le portail et la porte.Your personal code is sent via Airbnb message before arrival. The same code opens the gate and the door.

  1. 1
    Garez-vous devant la maisonPark in front of the house Sur l'herbe, dans la zone entourée en rouge sur la photo.On the grass, in the area outlined in red in the photo.
  2. 2
    Ouvrez le portailOpen the gate Tapez votre code sur le cadenas connecté, puis « déverrouiller ». Une fois le portail ouvert, raccrochez le cadenas et refermez-le.Type your code on the smart padlock, then "unlock". Once the gate is open, hook the padlock back and lock it.
  3. 3
    Entrez dans le CoconLet yourself in Tapez le même code sur le clavier Nuki : la porte s'ouvre dès le dernier chiffre. À l'intérieur, le bouton rond verrouille et déverrouille.Type the same code on the Nuki keypad: the door unlocks after the last digit. Inside, the round button locks and unlocks.
